# Natti Dosa Sales Dashboard – Excel

## Project Overview

This project presents an interactive **Natti Dosa Sales Dashboard developed using Microsoft Excel** to analyze sales performance and business trends.

## Objective

The objective of this project is to transform raw sales data into meaningful business insights and provide a simple dashboard for monitoring sales performance.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Advanced Excel Formulas
* Data Cleaning
* Conditional Formatting
* Data Visualization

## Key KPIs

* Total Sales
* Total Orders
* Total Quantity Sold
* Average Order Value
* Best-Selling Items
* Sales by Category
* Sales by Location
* Monthly Sales Performance

## Dashboard Features

* Interactive sales dashboard
* Monthly and daily sales analysis
* Product-wise sales performance
* Category-wise sales analysis
* Top-selling products
* Sales trend analysis
* KPI summary
* Interactive Pivot Charts and filters

## Data Analysis

The raw sales data was cleaned and organized in Excel before creating Pivot Tables and visualizations. The dashboard helps identify sales trends, high-performing products, and areas requiring improvement.

## Business Insights

The dashboard provides insights into:

* Overall sales performance
* Best-performing products
* Monthly sales trends
* Customer ordering patterns
* Product contribution to total revenue
* High and low-performing categories

## Project Outcome

This Excel dashboard demonstrates the ability to perform **data cleaning, sales analysis, KPI reporting, and business data visualization using Microsoft Excel**.
